# Brief Report — AI Campus Route Navigator

## Objective
The project models the CU Technology Campus as a weighted graph and compares two routing agents: PATHFINDER using Greedy Best-First Search and ORBIT using A* Search.

## Implementation
The graph is stored in `campus.json` and loaded at runtime. Nodes use the location labels visible on the assignment map; edges represent assumed walkable connections and carry approximate costs in metres. The heuristic is the shortest graph distance to the goal, computed using a small in-project routine over the campus graph. Both agents use the same heuristic. PATHFINDER prioritizes the estimated remaining cost `h(n)`, while ORBIT prioritizes `g(n) + h(n)`. A priority queue is used for each search.

The CSE routing rule is handled as part of the search state, rather than by editing the returned path afterward. A CSE destination requires entering through a Tower 2 entry and Lift Area before proceeding among CSE-labelled locations. A route exiting the CSE zone must return through Lift Area and a Tower 2 entry before continuing through the rest of campus.

## Experiments and observations
Eight source-destination pairs, including ordinary and CSE-related journeys, are run through both agents. For every run, the program records the path, total cost, nodes explored, and elapsed execution time in `results/results.csv`.

Greedy Best-First Search ranks frontier nodes only by the heuristic. It can therefore prefer a node that appears close to the goal while overlooking the cost already paid to reach it; it is not guaranteed to return the lowest-cost path. A* includes the travelled cost in its ranking, so the route choice reflects both progress so far and the estimated remaining distance. The agents may choose different paths when the heuristic ranking and accumulated route costs favour different frontier nodes. The CSE restriction reduces the legal choices and forces the required access corridor, which can make routes longer or constrain alternatives.

The exact route, node count, and execution time depend on the graph assumptions and machine. The CSV is generated by executing the algorithms; it does not contain manually assigned expected routes.

## Conclusion
The experiment illustrates the distinction between heuristic-only exploration and cost-aware search. A useful heuristic guides both agents, but the search strategy determines how the estimate is combined with the distance already travelled. The CSE access rule is an additional state constraint that both agents must respect.
